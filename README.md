# C_SortingAlgorithms
C implementation of various sorting algorithms. The intention of this project is to review the low level implementation of these sorting strategies directly in C as opposed to referencing a standard library implementation. Once implemented to goal will be to set up a variety of tests to compare and measure the performance of each approach.

See [docs/SPECIFICATION.md](docs/SPECIFICATION.md) for the project specification: organization, core interfaces, dataset format, and the measurement harness.
